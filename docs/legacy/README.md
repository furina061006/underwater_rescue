# 旧版平面目录留档

本目录保存重构前的两份原始资料，仅用于追溯，不参与当前构建与运行：

- `使用说明.txt`：2025-10-22 冻结备份时的操作说明与硬件参数。
- `SHA256SUMS.flat.txt`：冻结时对平面目录中所有文件的 SHA-256 清单。文件已经移动到
  `src/`、`tests/`、`bin/`、`docs/` 下，因此该清单不能再直接用于校验当前路径；
  当前目录结构的校验清单由 `make checksums` 生成在仓库根目录的 `SHA256SUMS.txt`。

旧版编译得到的四个逻辑测试二进制保存在 `build/legacy-bin/`（构建产物目录）。
